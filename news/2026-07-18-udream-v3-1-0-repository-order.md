uDream получил стабильную точку восстановления и понятную структуру для дальнейшей разработки без переноса проекта на телефон.

Что сделано:

— сохранен рабочий релиз v3.0.0;
— добавлен каталог запуска сохраненных версий;
— создан AGENTS.md с правилами безопасной разработки;
— оформлена документация по архитектуре, базе данных, версиям и восстановлению;
— добавлены автоматические проверки GitHub Actions;
— подключен единый порядок патчноутов через uNews;
— README оформлен как публичная страница проекта;
— разделены права на оригинальный код uDream и материалы исходных книг.

Что изменилось для пользователя:

— основной сайт продолжает работать как прежде;
— сохраненную версию можно открыть из меню сайта;
— история разработки стала понятной и проверяемой;
— будущие заметные изменения будут публиковаться через uNews в Telegram.

Важно:

MIT-лицензия относится к оригинальной программной оболочке, поисковой логике и документации uDream. Тексты книг, словарные толкования и PDF третьих лиц не объявляются собственностью автора приложения и сохраняют права исходных правообладателей.

Владелец проекта подтвердил, что архивные PDF были получены из открытых источников, которые предоставляли их для открытого распространения. Точные адреса и формулировки разрешений будут сохранены отдельно как документация происхождения.

Статус:

организационное и документационное обновление подготовлено для проверки перед объединением в main.

Короткий текст для Telegram:

Документационное обновление uDream: сохранена рабочая версия, приведены в порядок структура и документация, добавлены автоматические проверки и публикация будущих патчноутов через uNews. Отдельно зафиксировано, что MIT относится к оригинальному коду и интерфейсу uDream, а права на материалы книг остаются у их правообладателей.
