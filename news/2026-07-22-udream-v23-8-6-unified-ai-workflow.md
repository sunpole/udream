# uDream 23.8.6: единая работа из любого чата и устройства

В uDream создан единый GitHub-центричный порядок работы для телефона, Windows, MacBook, ChatGPT, Codex и других ИИ-агентов.

- Реальные GitHub-факты теперь имеют приоритет над старыми чатами и памятью ИИ.
- `WORK_STATUS.md` остаётся единой живой точкой активной задачи, ветки, прогресса и следующего шага.
- Новый чат обязан продолжать уже указанную ветку, а не создавать конкурирующую реализацию.
- Подключённый ИИ выполняет доступную GitHub-работу самостоятельно и обращается к владельцу только там, где нужен человек или недоступный инструмент.
- Добавлен подробный протокол `docs/AI_GITHUB_WORKFLOW.md`.
- Добавлена спецификация реальных изображений `docs/SCREENSHOT_AUTOMATION.md`.
- Каждый новый патчноут обязан добавить новый PNG/JPEG в том же Pull Request.
- Повторное использование старого изображения теперь блокируется автоматической проверкой.
- Патчноут хранит источник изображения, цель, commit и UTC-время захвата.
- `WORK_STATUS.md`, Pull Request template и проектный валидатор проверяются как единая система.
- Issue №19 обновлён и теперь хранит техническое задание D1.1, а не устаревающее живое состояние.
- Runtime приложения, PWA и активная база из 4 086 записей не изменялись.

Следующий отдельный операционный патч `23.8.7` автоматизирует захват desktop/mobile-изображений через настоящий Chromium и GitHub Actions artifacts. После него начинается D1.1 — исследование происхождения данных без изменения активной базы.
