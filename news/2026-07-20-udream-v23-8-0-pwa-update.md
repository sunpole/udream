# uDream 23.8.0: обновление PWA и установка с сайта

Исправлена ситуация, при которой сайт и установленное приложение могли продолжать показывать старую версию из кэша, хотя на GitHub Pages уже была опубликована новая версия.

- Service Worker теперь сразу активирует обновление через `skipWaiting()` и `clients.claim()`.
- Старые кэши удаляются только внутри семейства `udream-*`, не затрагивая другие проекты на том же домене.
- HTML, JavaScript, манифест и JSON получают стратегию «сначала сеть, затем кэш».
- Добавлен независимый `version.json`, который запрашивается без браузерного кэша.
- При обнаружении несовпадения версий приложение запрашивает обновление и выполняет защищённую однократную перезагрузку.
- При переходе со старого Service Worker открытая страница переводится на актуальную версию.
- На сайте появляется заметный баннер установки PWA.
- Баннер скрывается внутри уже установленного приложения.
- Кнопка «Установить» вызывает системное окно браузера, когда оно доступно.
- Для неподдерживаемых браузеров доступна ручная инструкция установки.
- Маленький крестик скрывает баннер только до следующей перезагрузки страницы.
- Обновлены версия приложения, package metadata и PWA manifest.
- Добавлены регрессионные проверки регистрации, запрета HTTP-кэша и немедленной активации Service Worker.

Активная база из 4 086 записей и тексты словаря не изменялись.

Изображение к публикации — специально подготовленная схема обновления PWA и баннера установки, а не снимок старой версии.
